## 📋 Description

**Eventure** is a modern event management system designed to streamline all aspects of the event lifecycle—from registration and planning to monitoring and notifications. With its dynamic interface and robust database architecture, Eventure ensures effectiveness, accessibility, and secure preservation of participant data.

Whether organizing academic lectures, student conferences, or campus-wide celebrations, Eventure empowers both organizers and attendees with hassle-free, tech-driven event experiences.

## ✨ Features & Scope

### 🔐 User Management
- User registration and authentication
- Role-based access control (Attendee & Organizer)
- Secure login system

### 📅 Event Creation & Management
- Create, update, and manage events
- Event details: title, description, schedules, and types
- Comprehensive event dashboard

### 🎯 Session Management
- Multiple sessions per event
- Session-specific details: materials, location, and time
- Session tracking and organization

### 📊 Event Tracker
- User event registration
- Check-in and check-out timestamp tracking
- Real-time attendance monitoring

### 🔔 Notification System
- Event updates and reminders
- Notification status tracking (read/unread)
- Event-related announcements

### 📈 Attendance Monitoring
- Track attendance for individual sessions
- SQL Server-based attendance records
- Comprehensive attendance reports

### 💬 Feedback System
- Post-event ratings and comments
- Attendee feedback collection
- Event quality assessment

### 📁 File & Material Management
- Upload event-related files and materials
- Session-specific resource sharing
- Document management for organizers

## ⚠️ Current Limitations

### Limited User Roles
- Supports only two basic user types: **Attendees** and **Organizers**
- No explicit support for administrators or support staff roles
- Limited role-based access control flexibility

### No Real-time Communication
- Notification system available, but no real-time chat functionality
- Limited dynamic interaction between organizers and attendees during events

### Basic Notification Features
- Simple message and read/unread status support
- Lacks advanced features:
  - Scheduled notifications
  - Priority tagging
  - Multi-recipient messaging

### No Payment Integration
- All event registrations are free
- No support for paid events or payment gateway integration
- Manual status management through database fields

### Event Session Simplicity
- Each session tied to a single event
- Limited session attributes (title, start time, end time)
- No support for complex session structures

### No Calendar Sync
- Users cannot sync events to personal calendars
- No automated reminders before event start times
- Manual event tracking required

### Scalability Not Yet Tested
- Designed for small to mid-sized events
- Performance under heavy user load not validated
- Concurrent event handling capacity unknown
